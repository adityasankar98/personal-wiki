## Concepts

_Ideas that recur across projects, each linked to where it appears._

- [[Deep Q-Network]] — A neural network that estimates the future reward of each action from game screens.
- [[Experience Replay]] — Storing past transitions and training on random samples of them.
- [[Exploration Rate]] — The share of random actions (epsilon) an agent takes while it learns.
- [[Held-Out Evaluation]] — Keeping test data separate from anything used to train, tune or choose a model.
- [[Model Capacity]] — How much a model can represent, set by its layers and parameters.
- [[Predictions vs Outcomes]] — Writing down what you expect before an experiment, then reporting where it was wrong.
- [[Reward Clipping]] — Squashing rewards to [-1, +1] for stable learning, at the cost of their relative size.
- [[Row Level Security]] — Postgres policies that restrict which rows each user can read or change.
- [[Session Token Auth]] — Signing users in and resolving an opaque bearer token to a user on every request.
- [[Word Embeddings]] — Learned vectors for each token; similar words end up with nearby vectors.
